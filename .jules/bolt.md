## 2025-02-28 - Vectorizing Correlation Matrices in Polars/Numpy
**Learning:** Polars/Numpy nested loops for operations like `np.corrcoef` on column pairs create severe O(N^2) bottlenecks as feature counts grow. Converting the entire selected dataframe to a single 2D Numpy array and calling `np.corrcoef(arr, rowvar=False)` performs the calculation instantly through C-level vectorization, completely bypassing the Python iteration overhead.
**Action:** When calculating pairwise metrics across dynamic columns, never loop through columns in Python. Instead, extract all required columns into a unified 2D numpy array (`.select(cols).to_numpy()`) and use vectorized numpy methods (`np.corrcoef`, `np.cov`). Always wrap with `np.atleast_2d()` to prevent scalar extraction errors on single-column edges, and handle zero-variance using `np.errstate(invalid='ignore', divide='ignore')`.
