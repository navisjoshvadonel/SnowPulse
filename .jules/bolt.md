## 2025-02-23 - Vectorized correlation matrix calculation
**Learning:** In Polars/Pandas dataframes, converting the entire dataframe to a Numpy array and running `np.corrcoef(arr, rowvar=False)` is significantly faster (orders of magnitude) than iterating column-by-column to calculate correlations using nested loops in Python. This is especially critical as O(N^2) bottlenecks appear when computing standard deviations and correlations for each combination.
**Action:** When a full correlation matrix across N columns is required, use `np.corrcoef(arr, rowvar=False)`. Also wrap the output with `np.atleast_2d()` to avoid indexing/iteration errors for single-column arrays, and apply `np.errstate(invalid='ignore', divide='ignore')` to handle zero-variance columns generating NaNs natively. Always select the columns using `.select(columns)` immediately before `.to_numpy()` to guarantee alignment.
