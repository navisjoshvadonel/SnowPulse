## 2024-09-07 - Vectorizing Correlation Matrix Calculations
**Learning:** Polars `.to_numpy()` does not automatically ensure correct column alignment or ordering when mixed with other operations, so you must explicitly call `.select(columns)` immediately before `.to_numpy()`. Using explicit Python nested loops for correlation matrix generation using `np.corrcoef` on 1D arrays causes a severe O(N^2) performance bottleneck, especially on large datasets.
**Action:** Always prefer fully vectorized operations in numpy (e.g., passing a 2D array to `np.corrcoef` with `rowvar=False`) over explicit Python nested loops. Ensure you explicitly call `.select(columns)` immediately before `.to_numpy()` to guarantee correct column alignment. Use `np.atleast_2d` to prevent indexing errors on single-column inputs, and use `np.errstate(invalid='ignore', divide='ignore')` along with `np.nan_to_num` to cleanly handle zero-variance columns producing NaNs.
