## 2024-08-28 - Vectorizing Correlation Matrix Computations
**Learning:** Polars `std()` behavior combined with Python nested loops over `np.corrcoef` resulted in significant O(N^2) bottlenecks when calculating correlation matrices for large datasets. `pl.col().std()` can return `None` or `NaN`, which needs to be handled properly when switching to vectorized `np.corrcoef` across the entire dataframe since it will pollute calculations.
**Action:** Replace pair-wise Python nested loops with single `np.corrcoef(arr)` calls on transposed NumPy arrays. Explicitly compute `stds` in a vectorized Polars query (`sub.select([pl.col(c).std() for c in cols])`) and map `NaN` or `None` std dev values to fallback outputs (`None` or `0.0`) inside the rendering loop to guarantee exact parity while achieving ~10x speedup. Always wrap with `np.atleast_2d()` to handle edge cases safely.
