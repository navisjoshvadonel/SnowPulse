## 2024-05-18 - [Vectorized Correlation Matrices]
**Learning:** Replaced O(N^2) python nested loops with vectorized numpy operations (`np.corrcoef(arr, rowvar=False)`) for dataset column correlations. This significantly speeds up correlation analysis for large datasets by leveraging C-level BLAS/LAPACK operations, preventing a severe performance bottleneck. I also learned to be careful with handling zero-variance columns when generating correlation matrices to prevent runtime warnings and indexing issues.
**Action:** Use `np.atleast_2d` to handle single column arrays safely, and use `np.errstate(invalid='ignore', divide='ignore')` to cleanly handle NaNs generated by zero-variance columns in `np.corrcoef`. Ensure `.to_numpy()` uses explicitly aligned columns (via `.select()`).
