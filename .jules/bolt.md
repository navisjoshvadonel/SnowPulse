## 2026-08-21 - Vectorized Correlation Matrix Calculation
**Learning:** Calculating correlation matrices element-by-element using nested Python loops and repeated calls to `np.corrcoef` on individual 1D arrays is an anti-pattern. This incurs massive overhead (O(N^2) where N is the number of numeric columns) due to Python loop overhead and repetitive allocations inside numpy, which degrades backend performance especially for datasets with many columns.
**Action:** Use `np.corrcoef(data, rowvar=False)` on the entire 2D dataset array instead. This pushes the entire O(N^2) mathematical operation down into highly optimized C routines and avoids looping overhead entirely, reducing processing time for 50 columns from ~0.25s to ~0.003s. Always look for fully vectorized operations in numpy/polars before writing explicit python loops over columns or rows. Note that `np.corrcoef` on a 1D array returns a scalar, so ensure dimensional consistency using `.ndim`.
