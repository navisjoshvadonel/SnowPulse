## 2024-11-20 - Vectorizing Correlation Matrices for Performance
**Learning:** Calculating `np.corrcoef` iteratively in a nested loop (O(N^2)) over pairs of columns significantly slows down backend data profiling for large datasets with many columns. While calculating pairwise correlation looks intuitive, it performs redundantly compared to a fully vectorized approach on multidimensional arrays.
**Action:** Always prefer `np.atleast_2d(np.corrcoef(arr, rowvar=False))` over nested `for` loops when computing correlation matrices in Python/Numpy. Wrap the return value with `np.atleast_2d()` when column counts are dynamic to avoid dimension errors on 1-column datasets. Ensure zero variance columns are correctly handled, masked out, or caught using `np.errstate(invalid="ignore", divide="ignore")` as needed by business logic.
