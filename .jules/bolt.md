## 2025-02-20 - Vectorized Correlation Matrix Calculation
**Learning:** Nested loops iterating through each pair of columns in a Polars DataFrame to calculate correlations one-by-one is highly inefficient, exhibiting O(N^2) complexity with substantial overhead from repeatedly converting each column to NumPy and calling `np.corrcoef`. By extracting the relevant subset of columns directly into a single 2D NumPy array (e.g. `arr = df.select(cols).to_numpy()`) and passing it entirely into `np.corrcoef(arr, rowvar=False)`, the underlying highly-optimized C libraries perform the calculation in orders of magnitude less time.
**Action:** When computing any pairwise metric across all features (like correlation, covariance, or distances), aggressively favor built-in matrix operations on entire 2D arrays rather than looping over pairs of columns manually. Ensure correct column ordering is enforced explicitly by using `.select(cols)` immediately before calling `.to_numpy()`. Handle edge cases for zero-variance or single columns by using `np.atleast_2d` and `np.errstate(invalid="ignore", divide="ignore")` to prevent errors from single-column scaling or division by zero, filling the resulting NaNs as needed downstream.
