## 2026-09-18 - [Vectorized Correlation Matrix Optimization]
**Learning:** Polars DataFrames converting to Numpy arrays for column-specific vectorized operations like correlation matrices can be dramatically sped up by replacing explicitly nested loops calling `np.corrcoef` on 1D arrays with a single vectorized `np.corrcoef` on the entire 2D array. This prevents severe O(N^2) bottlenecks when calculating pairwise correlations across many columns.
**Action:** Prefer fully vectorized operations in numpy (e.g., using `np.corrcoef(arr, rowvar=False)` on 2D arrays) over explicit Python nested loops. When column counts are dynamic, wrap the result of `np.corrcoef` with `np.atleast_2d()` to prevent indexing/iteration errors (as it returns a 0-D scalar for single-column inputs). Use `np.errstate(invalid='ignore', divide='ignore')` to cleanly handle zero-variance columns producing NaNs.
