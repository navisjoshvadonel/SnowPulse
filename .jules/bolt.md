## 2024-05-24 - [Avoid Nested Python Loops for Correlation Matrices]
**Learning:** In pandas/polars, generating a correlation matrix using a nested `O(N^2)` Python loop iterating over columns and repeatedly calculating 1D array correlations is extremely slow due to Python overhead. Converting a Polars DataFrame to a 2D numpy array and calculating correlation across all variables simultaneously using `np.corrcoef(data, rowvar=False)` performs orders of magnitude faster (e.g., >40x speedup for 50 columns).
**Action:** When working with numeric tabular data features, prefer fully vectorized 2D operations over explicit column-by-column Python iteration. Ensure you use `np.atleast_2d` and `np.errstate(invalid='ignore', divide='ignore')` to cleanly handle dynamic shapes and zero-variance columns without exceptions.
